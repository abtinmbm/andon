## Fault trials

Each trial starts the fault from a green light and waits for the board to stop the fan by itself. Start to fan off is from the command that starts the fault to the gate pin reading back low (the power cut; spin-down is not timed). For a fitted fault that command is `fan on`, so the 5 s hold-off and the kick-start are inside the time. Times are mean ± sd over the caught trials, then the range. A fault fitted once has no normal stretch before its trials, so it has no false-stop count (-).
